# JMS186 Drop Data
## ドロップ率について
+ 下限値
	+ 1/1000000
	+ [R8]0.000001 という表記が下限値となる
+ `サーバー上のドロップ値`の持ち方
	+ [R8]0.000001 * 1000000をint型の整数で持つ
+ ドロップ率をパーセントで表示する場合
	+ `サーバー上のドロップ値` * 100.0 / 1000000
+ 内部的な処理
	+ 0から999999の乱数を発生させて`サーバー上のドロップ値`内の数値が得られたらドロップ判定を出す
+ まぁ適当です

## 2010_09.json
+ ドロップデータ本体
	+ 当時の攻略本, モンスターブックデータ, DropWikiからデータを収集
	+ ドロップデータを確定させる処理
		+ モンスターブックデータを最優先で利用し、アイテムIDを確定させる
		+ 攻略本に記載のデータはおそらくサーバーのデータベースそのものなので、こちらも正しいものとしてアイテム名を確定させる
			+ 一部誤字などがあるが、可能な限りアイテム名を確定させる
			+ 該当するアイテム名が1つの場合は、アイテムIDが確定する
			+ アイテム名が重複している場合はアイテムIDが確定しない
		+ DropWikiの情報を参照してアイテムIDが1つに確定しなかったものを確定させる
			+ しかし、DropWikiも完全ではないので、一部データに欠損がある
		+ 最終的にアイテムIDが確定しなかったものをcandidatesに突っ込む
			+ 海外情報を参照すればアイテムIDを確定させられる可能性がある
+ prob_est
	+ trueの場合は確率が適当に設定されているという意味
	+ このフラグがついていないものは公式通りの確率のはず
+ idがnull
	+ アイテムIDが未確定の意味
+ candidates
	+ アイテムIDが何れかの可能性が高いという意味
